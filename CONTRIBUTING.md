# Contributing to MPKNet

Thanks for your interest in contributing!

## Ways to Contribute

### Feedback & Discussion
- **Conceptual critique**: Is the biological motivation sound? Are there aspects of LGN organization I'm missing or misrepresenting?
- **Robustness evaluation**: Ideas for additional benchmarks or stress tests
- **Literature pointers**: Papers on LGN, parallel visual processing, or bio-inspired architectures I should know about

### Code Contributions
- Bug fixes and documentation improvements welcome via PR
- For larger architectural changes, please open an issue first to discuss

### Collaboration
If you're interested in:
- Testing MPKNet on new datasets (especially medical imaging, robotics, edge deployment)
- Extending the architecture (temporal dynamics, recurrence, foveation)
- Co-authoring papers

Please reach out via my [website](https://djlougen.github.io/PersonalWebsite/).

## Current Focus Areas

1. **Konio-gating mechanism**: The K-pathway as cross-stream modulator is the novel contribution - feedback on this is especially valuable
2. **Augmentation insensitivity**: Understanding why MPKNet seems to need less augmentation than standard CNNs
3. **Medical imaging applications**: Testing on endoscopy, radiology, pathology datasets

## Code Style

- Python 3.8+
- PyTorch
- Type hints appreciated but not required
- Keep it simple - the goal is biological interpretability, not clever tricks
