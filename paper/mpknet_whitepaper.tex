\begin{abstract}
We present MPKNet, a biologically-inspired convolutional neural network that models the Magnocellular (M), Parvocellular (P), and Koniocellular (K) pathways of the Lateral Geniculate Nucleus (LGN). Drawing from cross-species evolutionary priors observed in mammals from tree shrews to primates, MPKNet implements parallel visual streams with biologically-motivated receptive field sizes and a novel Konio gating mechanism for cross-stream modulation. Our architecture achieves competitive accuracy on CIFAR-10 with only 0.54M parameters while exhibiting fractal dynamics (DFA $\approx$ 0.52) consistent with biological neural systems. We introduce CellPop, a structured downsampling module inspired by retinal ganglion cell population responses, and demonstrate that the K-pathway can serve as a context-aware gate for modulating detail (P) and gist (M) streams. These results suggest that incorporating evolutionary priors from comparative neuroanatomy can yield efficient, interpretable visual architectures.
\end{abstract}

\section{Introduction}

The mammalian visual system processes information through parallel pathways that have been conserved across evolutionary time. The Lateral Geniculate Nucleus (LGN), a thalamic relay between retina and visual cortex, contains three main cell types that form distinct processing streams:

\begin{itemize}
    \item \textbf{Magnocellular (M) pathway}: Large receptive fields, fast temporal dynamics, motion and global ``gist'' processing
    \item \textbf{Parvocellular (P) pathway}: Small receptive fields, high spatial acuity, color and fine detail
    \item \textbf{Koniocellular (K) pathway}: Context relay, cross-layer modulation, blue-yellow color signals
\end{itemize}

The tree shrew (\textit{Tupaia belangeri}) provides an excellent model for studying these pathways due to its clearly laminated LGN structure, where M, P, and K cells occupy distinct layers rather than being intermixed as in primates \citep{conley1984laminar}. This architectural clarity offers a natural blueprint for neural network design.

Modern deep learning has largely ignored these biological priors, instead favoring uniform architectures like ResNet or Vision Transformers. We hypothesize that incorporating the parallel-stream organization of the LGN can yield networks that are:
\begin{enumerate}
    \item More parameter-efficient by specializing pathways for different spatial frequencies
    \item More interpretable by maintaining functional separation between streams
    \item Exhibiting dynamics closer to biological neural systems
\end{enumerate}

\section{Related Work}

\subsection{Bio-Inspired Visual Architectures}

Early convolutional networks drew inspiration from the visual cortex \citep{fukushima1980neocognitron, lecun1989backpropagation}, but subsequent development has largely abandoned explicit biological correspondence. Recent work has revisited bio-inspired design:

\begin{itemize}
    \item \textbf{Gabor-based first layers}: Several works initialize CNNs with Gabor filters to mimic V1 simple cells \citep{luan2018gabor}
    \item \textbf{Recurrent processing}: CORnet and related models add recurrence to match ventral stream dynamics \citep{kubilius2018cornet}
    \item \textbf{Divisive normalization}: Implementing canonical cortical computations in neural networks \citep{burg2021learning}
\end{itemize}

However, none of these explicitly model the LGN's parallel pathway organization.

\subsection{Multi-Scale Processing in Deep Learning}

Multi-scale processing has been explored through:
\begin{itemize}
    \item Feature pyramid networks for detection \citep{lin2017feature}
    \item Multi-resolution branches in HRNet \citep{wang2020deep}
    \item Dilated convolutions for varying receptive fields \citep{yu2015multi}
\end{itemize}

MPKNet differs by grounding the multi-scale design in specific biological constraints.

\subsection{The Tree Shrew LGN}

The tree shrew LGN has six layers with distinct functional properties \citep{conley1984laminar, usrey1999quantitative}:
\begin{itemize}
    \item Layers 1-2: Small cells, slow responses (K-like)
    \item Layers 3-4: Medium cells, color-opponent (P-like)
    \item Layers 5-6: Large cells, fast transient responses (M-like)
\end{itemize}

This laminar organization is conserved across mammals, suggesting evolutionary optimization.

\section{Methods}

\subsection{Architecture Overview}

MPKNet consists of five main components:

\begin{enumerate}
    \item \textbf{PreMPK}: LGN-like preprocessing with high-pass (Parvo) and low-pass (Magno) filtering
    \item \textbf{CellPop}: Structured downsampling using pixel unshuffle to model retinal sampling
    \item \textbf{Parallel Pathways}: M, P, and K streams with biologically-motivated kernel sizes
    \item \textbf{K-Gate}: Konio-pathway gating mechanism for cross-stream modulation
    \item \textbf{Fusion}: Concatenation and projection for classification
\end{enumerate}

\subsubsection{PreMPK Module}

The PreMPK module implements center-surround filtering inspired by LGN relay cells:

\begin{equation}
    x_P = \text{HPF}(x) = x - G_\sigma * x
\end{equation}
\begin{equation}
    x_M = \text{LPF}(G_\sigma * L(x))
\end{equation}

where $G_\sigma$ is a Gaussian kernel, $*$ denotes convolution, and $L(\cdot)$ extracts luminance for the Magno pathway.

\subsubsection{CellPop Module}

CellPop implements structured spatial downsampling using pixel unshuffle followed by grouped convolutions:

\begin{equation}
    \text{CellPop}(x) = W_{1\times1} \cdot \sigma(\text{BN}(\text{PixelUnshuffle}_s(x)))
\end{equation}

This models the discrete sampling of retinal ganglion cells while preserving local spatial relationships.

\subsubsection{Parallel Pathways}

Each pathway uses kernel sizes reflecting biological receptive field properties:

\begin{itemize}
    \item \textbf{Magno}: 7$\times$7 $\rightarrow$ 9$\times$9 (large RF, global gist)
    \item \textbf{Parvo}: 4$\times$4 $\rightarrow$ 3$\times$3 $\rightarrow$ 2$\times$2 $\rightarrow$ 2$\times$2 (small RF, fine detail)
    \item \textbf{Konio}: 5$\times$5 $\times$ 3 layers (intermediate, modulatory)
\end{itemize}

\subsubsection{Konio Gating}

The novel K-Gate mechanism allows the Konio pathway to modulate M and P streams:

\begin{equation}
    \mathbf{k} = \text{GAP}(K) \in \mathbb{R}^{d_k}
\end{equation}
\begin{equation}
    g_P = \sigma(W_P \mathbf{k}), \quad g_M = \sigma(W_M \mathbf{k})
\end{equation}
\begin{equation}
    P' = P \odot g_P, \quad M' = M \odot g_M
\end{equation}

where GAP is global average pooling and $\sigma$ is sigmoid activation. This implements cross-stream attention based on the K-pathway's contextual representation.

\subsection{Training Protocol}

We employ modern training techniques:
\begin{itemize}
    \item SGD with momentum (0.9) and Nesterov
    \item Cosine learning rate schedule with warmup
    \item Stochastic Weight Averaging (SWA)
    \item Exponential Moving Average (EMA) of weights
    \item Mixup augmentation ($\alpha = 0.2$)
    \item Label smoothing (0.1)
\end{itemize}

\subsection{Fractal Dynamics Analysis}

We measure temporal dynamics of prediction confidence using Detrended Fluctuation Analysis (DFA):

\begin{equation}
    F(n) \propto n^\alpha
\end{equation}

where $\alpha$ is the DFA exponent. Biological neural systems typically exhibit $\alpha \in [0.5, 0.75]$, indicating long-range temporal correlations characteristic of systems at criticality.

\section{Discussion}

\subsection{Biological Plausibility}

Our architecture captures several key features of LGN organization:
\begin{itemize}
    \item Parallel processing with different spatial scales
    \item Center-surround preprocessing
    \item Cross-stream modulation via the K-pathway
    \item Discrete spatial sampling modeling retinal mosaics
\end{itemize}

\subsection{Limitations}

Current limitations include:
\begin{itemize}
    \item Lack of temporal dynamics (frame-by-frame processing)
    \item Fixed kernel sizes rather than learned receptive fields
    \item No explicit modeling of retinotopy
\end{itemize}

\subsection{Future Directions}

Promising extensions include:
\begin{itemize}
    \item Adding recurrence to model temporal dynamics
    \item Extending to video with motion-sensitive Magno stream
    \item Incorporating foveated attention based on the K-pathway
\end{itemize}

\section{Conclusion}

MPKNet demonstrates that incorporating evolutionary priors from comparative neuroanatomy---specifically the parallel M, P, and K pathways of the tree shrew LGN---can yield efficient visual architectures with biologically-plausible dynamics. The novel K-Gate mechanism provides a principled way to implement cross-stream modulation. We hope this work encourages further exploration of bio-inspired design principles in deep learning.
